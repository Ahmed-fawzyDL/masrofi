# مصروفي

تطبيق موبايل بسيط لمتابعة المصاريف اليومية والتحصيلات بالجنيه المصري. بيشتغل من المتصفح ويتضاف للشاشة الرئيسية زي أي تطبيق، ومن غير إنترنت بعد أول فتح.

**رابط التطبيق:** https://ahmed-fawzydl.github.io/masrofi/

---

## المميزات

| الميزة | التفاصيل |
|---|---|
| المصروفات والتحصيلات | تسجيل أي مصروف أو تحصيل بالمبلغ والبند وطريقة الدفع والتاريخ وملاحظة |
| التحويلات | نقل فلوس بين طرق الدفع، زي سحب من الفيزا للكاش |
| طرق الدفع | كاش، إنستاباي، فيزا / كارت، حساب بنكي، محفظة موبايل، مع إمكانية إضافة أي عدد بالبنك والرصيد الافتتاحي واللون |
| البنود | بنود مصروفات وتحصيلات قابلة للإضافة والتعديل والإيقاف |
| التحصيلات السنوية | بند التحصيل يتحدد شهري أو سنوي أو متغير، والسنوي يتابَع بشهر الاستحقاق والمبلغ المتوقع وحالته (اتحصّل / منتظر / متأخر) |
| قفل الشهر | قفل الشهر بيحفظ ملخصه وأرصدته ويمنع تعديل حركاته، ويقدر يتفتح تاني |
| التقارير | ملخص الشهر حسب البند وطريقة الدفع، وملخص السنة برسم بياني شهر بشهر |
| كشف الحساب | لأي طريقة دفع برصيد أول وآخر المدة والرصيد المتحرك، أو لأي بند بالإجمالي التراكمي |
| النسخ الاحتياطي | تنزيل كل البيانات في ملف واحد، واسترجاعها على أي موبايل |

---

## التثبيت على الموبايل

**أندرويد (Chrome):**
1. افتح رابط التطبيق.
2. دوس على النقط التلاتة ⋮ فوق.
3. اختار **إضافة إلى الشاشة الرئيسية**.

**آيفون (Safari):**
1. افتح رابط التطبيق.
2. دوس على زرار المشاركة تحت.
3. اختار **إضافة إلى الشاشة الرئيسية**.

---

## أول استخدام

1. ادخل **الإعدادات** وظبّط طرق الدفع: اسم البنك والرصيد الحالي لكل واحدة.
2. راجع البنود وضيف أو عدّل اللي تحتاجه.
3. من زرار **+** في النص تحت سجّل أول حركة.

> **مثال:** دفعت 150 جنيه بنزين كاش ← دوس + ← مصروف ← 150 ← مواصلات وبنزين ← كاش ← سجّل.

## البيانات والخصوصية

- كل البيانات بتتحفظ **على الموبايل نفسه بس**، ومش بتترفع على GitHub ولا على أي سيرفر.
- الـ repository ده فيه **ملفات التطبيق فقط**، ومفيش فيه أي أرقام أو حركات.
- لو مسحت بيانات المتصفح أو غيرت الموبايل، البيانات هتضيع إلا لو عندك نسخة احتياطية.

**النسخ الاحتياطي:** من **الإعدادات ← النسخ الاحتياطي ← تنزيل نسخة**، وابعت الملف لنفسك على الإيميل أو Drive. يفضل مرة كل شهر، مثلاً بعد قفل الشهر.

**الاسترجاع:** من **الإعدادات ← النسخ الاحتياطي ← استرجاع نسخة** واختار آخر ملف.

## ملفات المشروع

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق كله: الشاشات والتصميم والحسابات |
| `manifest.json` | اسم التطبيق وأيقونته وألوانه لما يتضاف للشاشة الرئيسية |
| `sw.js` | بيخلي التطبيق يفتح من غير إنترنت |
| `icon-192.png` / `icon-512.png` | أيقونة التطبيق |

## التحديث

لتحديث التطبيق: ارفع ملف `index.html` الجديد مكان القديم من **Add file ← Upload files ← Commit changes**. التحديث بيظهر على الموبايل خلال دقايق، والبيانات المسجلة مش بتتأثر.
